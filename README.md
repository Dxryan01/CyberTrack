# CyberTrack

A lightweight cybersecurity learning tracker built with HTML, CSS and JavaScript.

CyberTrack is a small web application designed to help track cybersecurity learning activities, including CTF challenges, courses, personal projects and technical concepts.

## Features

- Add learning activities.
- Categorize activities (CTF, Courses, Concepts, Projects).
- Assign a status to each activity (To Do, In Progress, Completed).
- Track activity statistics.
- Delete activities.
- Save activities locally using the browser's LocalStorage.
- Responsive interface.

## Technologies

- **HTML5** – Application structure.
- **CSS3** – Styling and responsive design.
- **JavaScript** – Application logic and DOM manipulation.
- **LocalStorage API** – Client-side data persistence.

## Getting Started

1. Clone the repository:

```bash
git clone https://github.com/YOUR_USERNAME/CyberTrack.git
```

2. Navigate to the project directory:

```bash
cd CyberTrack
```

3. Start a local development server:

```bash
python3 -m http.server 8000
```

4. Open the following address in your browser:

```text
http://localhost:8000
```

No additional dependencies or backend configuration are required.

## Learning Context & AI Assistance

CyberTrack was initially conceived as a small personal project to refresh my web development fundamentals in preparation for my second year of a Bachelor's degree in Cybersecurity.

The project was developed using an AI-assisted **vibe coding** approach, with ChatGPT helping generate code, explain key concepts and explore implementation choices.

Rather than focusing exclusively on writing code from scratch, the goal was to revisit and better understand fundamental web development concepts, particularly:

- HTML structure and semantics.
- CSS layouts and responsive design.
- JavaScript functions, arrays and event handling.
- DOM manipulation.
- JSON serialization and deserialization.
- Browser-based data persistence with LocalStorage.

This project also represents an opportunity to explore the practical use of AI-assisted development as a learning tool.

## Limitations

- Data is stored locally in the browser.
- Activities are not synchronized across devices.
- There is no authentication or backend database.
- Clearing browser storage may result in data loss.
